# GVB / Gappie — current flow evidence

Research date: **2026-10-04**. Scope: official GVB guidance and GVB-owned store descriptions/release notes. No native app was installed or operated for this document. These findings establish documented capabilities and paths, not measured interaction quality, live-data accuracy, or a verified screen-by-screen audit.

## Version and evidence boundary

- **iOS:** the Dutch App Store lists **2.27.2**, dated **7 Sep**. The year is not printed beside that entry; **2026 is inferred** from the surrounding chronological history, which explicitly dates the preceding December releases to 2025. [GVB’s iOS listing](https://apps.apple.com/nl/app/gvb-reis-app/id1544439867)
- **Android:** Play reports **updated 4 September 2026**. Its public page did not expose a version number in the retrieved text. [GVB’s Play listing](https://play.google.com/store/apps/details?id=nl.gvb.reizigersapp&hl=en)
- Both latest release descriptions say the balance checker is being phased out; the GVB overview still advertises it. Treat this as a documentation conflict, not an available feature to copy. [iOS release notes](https://apps.apple.com/nl/app/gvb-reis-app/id1544439867), [Play release notes](https://play.google.com/store/apps/details?id=nl.gvb.reizigersapp&hl=en), [GVB overview](https://www.gvb.nl/reisinformatie/gvb-app)
- Official web guides are undated. Direct retrieval of several `www.gvb.nl` pages returned HTTP 403; their indexed official content was readable through web search. Search crawl dates are not publication dates. Developer store copy can also lag shipped behavior.
- The December 2023 Conclusion design case is historical context. It does not establish the current navigation or prove a behavior survived subsequent releases. This document does not use it as evidence.

## Information architecture: defensible reconstruction

The evidence supports a **task-oriented set of surfaces**: a personal dashboard, a departures area, a journey planner, a map, and a More area containing preferences and alerts. This is a reconstruction from the documented entry points, **not a verified current tab bar, order, or complete menu tree**. GVB also has ticket purchase, account and service capabilities, but those are outside this stop/departure comparison. [GVB overview](https://www.gvb.nl/reisinformatie/gvb-app), [GVB travel-information guide](https://gvb.nl/reisinformatie/werking-reisplanners-halte-info-deelvervoer), [Play listing](https://play.google.com/store/apps/details?id=nl.gvb.reizigersapp&hl=en)

The practical distinction to test is between a quick **stop → direction → next departures** decision and a more deliberate **origin/destination → journey alternatives → active journey** decision. That distinction is an analysis hypothesis, not a claim that every arrow corresponds to one GVB tap.

## Required hands-on checks before copying a pattern

1. Record platform, build, language, permission state, location and time; capture the first viewport with fresh app state.
2. At one interchange, find nearby stops, inspect both directions and several departures, then return without losing context. Record actual taps and visible rows.
3. Open a vehicle position from a departure; inspect with and without the map if possible. Distinguish timetable prediction, actual position and device location. Observe missing/stale data.
4. Plan the same origin/destination manually and from the map. Change the origin, mode and time separately; verify which preferences persist.
5. Save and reopen a stop, direction/route and destination. Establish whether these are distinct and whether authentication is needed.
6. Deny location and notification permissions separately. Verify the recovery action, retained choices and subsequent launch behavior.
7. Configure accessibility needs; inspect a journey involving a lift problem. Repeat with large text and a screen reader.

No product changes follow automatically from this matrix. Use the checks alongside the Expadu baseline to choose which interaction solves the user’s actual decision with less effort.
