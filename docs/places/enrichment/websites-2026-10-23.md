# Reading places' own websites — 23 Oct 2026 (owner-approved, one-off, local only)

**What:** `php artisan places:read-websites --kinds=cafe,library,coworking` reads each place's own
website for what someone choosing a place to work needs: guest Wi-Fi, power sockets, laptop policy
(and laptop-free times). Claude Haiku 5.5, effort low, budget cap $10.

**Rules followed:** robots.txt honoured for `ExpaduBot/1.0 (+https://expadu.com)`; one request at a
time per site (1.2 s apart); only the homepage plus one hours/contact/about/FAQ link on the same site;
chain sites (one website for 3+ places) skipped. A fact is kept only with the exact sentence it came
from, found on the page; nothing else of the page is stored. Recorded as provider `website` with
`evidence` (the quote), `source_url` and `observed_at`. OSM is never overwritten.

**Run:** 291 sites — 216 read, 13 blocked by robots.txt, 62 unreachable, 10 chain sites skipped;
111 sites stated something. Model cost **$0.11**.

**Hours were dropped.** Website hours were extracted for 107 sites, but in a spot check the model
misread day ranges ("Mittwoch – Sonntag 11–18" became every day) or guessed days from bare times.
Because differing hours are flagged as conflicting, wrong website hours also hid correct OSM hours
(café hours 57% → 52%). Website hours are therefore not recorded (`--with-hours` turns them back on);
all website-hours observations were removed.

**Result (places with the fact):** cafés Wi-Fi 61 → 66, sockets 0 → 1, laptop policy 0 → 4;
libraries laptop policy 0 → 1; coworking Wi-Fi 0 → 2. Cafés' own websites rarely say any of this.

**Not run:** restaurants and gyms (≈1,150 more sites) — their sites state even less about Wi-Fi,
sockets or laptops, so the requests aren't worth it.

**Composer:** `practical.laptops` = no excludes a place from work asks; `limited` with
`laptops:conditional` (OSM day names, e.g. "Sa-Su") excludes it on those days.
