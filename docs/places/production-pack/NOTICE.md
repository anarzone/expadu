# Source attribution and reuse

The selected records preserve their provider, provider record ID, source URL,
observation date, original record, record checksum and licence identifiers.
Selection and normalization do not verify every source assertion independently.

- OpenStreetMap records: © OpenStreetMap contributors. Data is available under
  the [Open Database License 1.0](https://www.openstreetmap.org/copyright).
  Preserve attribution, access to the applicable database and the licence when
  publishing or distributing derived OSM data. The publisher's licence text is
  included in `licenses/ODbL-1.0.txt` and is available at the
  [Open Data Commons licence page](https://opendatacommons.org/licenses/odbl/1-0/).
- Overture records: Overture Maps Foundation and the contributors named in each
  record's `raw.properties.sources`. The selected Overture additions in this
  pack carry CDLA-Permissive-2.0. The agreement is included in
  `licenses/CDLA-Permissive-2.0.txt`; retain it with shared data. See the
  [provider attribution statement](https://docs.overturemaps.org/attribution/#places).

No media rights are granted by a place's data licence. Image links in original
OSM records remain unapproved references. This preparation neither downloads
nor publishes those images. It adds no Stadt Köln structured dataset or image
provider. Preserve the application's existing approved-rights media selector.

The held-record review contains references to other Overture licences because
the full research inventory is broader than this selected release. Held
records are not included in the application import.
