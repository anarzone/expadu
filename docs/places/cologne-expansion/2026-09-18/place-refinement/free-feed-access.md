# Free tourism feed access — preparation, not submission

No provider registration, terms acceptance, message or paid request has been submitted. No credentials should be pasted into a chat or saved in this research package.

## Data Hub NRW

- Public discovery: https://tourismusverband.nrw/themen/datenmanagement/open-data-finder
- Terms: https://tourismusverband.nrw/allgemeine-geschaeftsbedingungen-data-hub-nrw
- Intended use: Cologne place discovery and matching for Expadu, retaining source identifiers, coordinates, categories, per-photo creator and licence metadata, and attribution.
- Access requested: free B2B data access for Cologne POIs and gastronomy, including media metadata and stable record identifiers.
- Missing owner details: contact salutation, full name, organisation's legal name, work email, organisation seat/location and user type. These must be supplied or confirmed; they must not be inferred from a repository name.
- Asset licences must be checked individually. Free feed access is not blanket photo permission.

The public catalogue advertises a broader regional inventory, but that is not a Cologne-only image count. Three stored detail samples show the practical uncertainty: Café Goldjunge has no hero/gallery image; Kölner Dom has licensed gallery entries; Stadtwald reuses an already-known destination.one asset. Attempts using page/pageSize query parameters returned the same record IDs instead of reliable pagination. No private application bearer token was used to obtain full data.

## Open Data Germany

- Registration: https://open-data-germany.org/zugang-anfordern/
- Terms: https://open-data-germany.org/2023-03-16-agb-datennutzer-knowledge-graph_dzt/
- Intended access selection: API for Cologne POIs/gastronomy and attached individually licensed media.
- Proposed organisation type, subject to owner confirmation: Firmen und Tech-Dienstleister.
- Missing fields: contact first and last name, legal company/organisation name, work email and confirmation of organisation type. The form also requires its privacy/terms acknowledgements and an anti-spam step.

Before submission, present the actual completed registration details and terms acknowledgements for review. Do not claim either service provides a particular number or percentage of suitable Cologne photos until authenticated retrieval, overlap analysis, rights checks and place matching are complete.
