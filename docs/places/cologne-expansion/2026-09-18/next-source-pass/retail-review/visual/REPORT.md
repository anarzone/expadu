# Retail/hotel visual and health review

All 34 selected images were inspected individually. **32 are visually suitable exteriors; 2 selected heroes are rejected** (Reserved: Kämpgen dominates; Opera: different hotel branding and restaurant-dominated frontage). All 34 retain the current-operation check, and none is approved for publication.

The files are healthy decoded JPEGs. Actual SHA-256, dimensions, byte count, original Commons SHA-1, capture date, source page, original/thumbnail URLs, licence and source artist/credit are stored per image in `decisions.jsonl`. Licence/credit values retain the source HTML. This records evidence, not rights approval.

## Acquisition discrepancy

44 of the allowed 45 HTTP requests were used (2 metadata batches, 42 image reads). Eight portraits exceed the 1280px research acquisition cap. The second batch requested 720px width/1280px height, but Commons returned 960px URLs and bytes while reporting smaller thumbnail dimensions. Final records use decoded dimensions and preserve the API-reported values separately. No further requests or resizing were performed. Exceeding the acquisition cap does not itself make a photo unsuitable for the product.
