# Independent retail/hotel Commons proposal review — 18 September 2026

Reviewed the completed collection: **1,802 associations across 284 catalogue place groups**. This is conservative metadata screening against the existing catalogue, with no new network requests or visual image inspection. All input groups received an explicit rule-based outcome, and all shortlisted venue groups were manually screened using their supplied captions, photo coordinates and catalogue identity/address context.

**34 distinct incremental destination candidates** survive for actual photo/currentness review. They comprise 67 retained file-to-place associations, not 67 places. None is approved for publication. These are strong metadata candidates, not a claim of 34 visually or currently verified destinations.

## Decisions that prevent inflated coverage

- Apple’s Rhein-Center rows receive Schildergasse photos roughly 8.5 km away and are not matched. The actual central branch retains ordinary named exterior-photo candidates; the contradictory “Schildergasse 24” filename is held, and pandemic closures/queues are rejected.
- Foto Lambertin’s north-Domplatte pavilion and Wallrafplatz shop are different branches. Only the nearby north pavilion row is shortlisted against its named photos.
- UNIQLO’s photo identifies the former Hohe Straße 52 premises, while the catalogue is the Schildergasse 24–30 store. It is rejected despite only about 130 m separation. The independently verified current UNIQLO photo from the storefront pass is separate.
- Taschen depicts the former Hohenzollernring 28 shop closed since 2017, not the catalogue’s Neumarkt 3 store. Levi’s Hohe Straße does not match the Ehrenstraße branch.
- Hyatt Regency, Hohenzollernbrücke, Stadtwald, King Georg Büdchen and the Habsburgerring 9–13 hotel building already have illustrated catalogue subjects. Empty duplicate/tenant rows do not generate new destination counts. The Steigenberger photo may improve current branding, but is excluded from new-subject gain because the same hotel building already has an older Barceló image.
- La Société was already shortlisted by the earlier independent Commons review and is excluded from this pass’s incremental count.
- Kiosk, REWE, EDEKA, Merzenich and other chain/generic-name matches are not propagated to every branch. A generic kiosk only 5 m from a photograph remains held without sufficient exact identity/address context.
- Waidmarkt-square proposals depict neighboring hotels. Rimowa museum/luggage detail candidates are rejected while its named flagship-store exterior candidate survives. Ads, shop-sign details, queues, people/event images and obsolete/closed premises do not become destination-photo gains.
- A distant camera can photograph a building through a long lens. The conservative distance rule rejects the supplied association for this shortlist when over 1 km, but does not prove the named subject is absent. The explicitly named Best Western telephoto is left out; it would require separate visual review.
