# Additional named everyday destinations

This local-only continuation expands the existing Places/Composer catalogue beyond leisure and food. It uses an explicit OpenStreetMap allowlist for physical retail, customer services, health venues, community, accommodation and fitness. A school, street, parking node, vacant shop, arbitrary office or anonymous building does not become a destination through a fallback category.

`categories.py` maps supported OSM types to the native SpotCategory contract. `selection.py` requires source names, open-data rights, valid points and conservative identity checks against every native row, prior additions and the new cohort. It preserves previous explicit manual/closure/identity holds and never merges or reactivates an existing place. Full source tags remain in Spot.tags and Composer's existing flattened tag vocabulary; practical observation fields retain the supported capability tags.

`run.py select` freezes a separate private selection. `fetch` reads exact current OSM objects and complete node geometry in cohorts of 750, retaining the existing 20,000-node bound per cohort. Ways are read before and after their nodes. `native-source-check` uses PostGIS to reproduce each representative point within one metre; mismatched cached points remain held. This pass does not convert a source centre into a verified entrance.

`freeze-runtime` binds the application and helper code. `rehearse` validates every frozen input, replays the previous two additions and 690 facility qualifications, then applies only accepted new named identities through the native observation/import actions. Every exported record must be present through both PlaceResource and CandidateRepository::byIds. It verifies typed nearby Composer requests, native detail/list access, strict-free fee evidence, unchanged prior candidates/media, and identical additive replay. All mutations roll back and PostgreSQL sequences are restored. `failure-check` verifies cleanup after a forced failure; `verify-snapshot` independently compares the original ten-table baseline. No user or live environment data is included.

The full trial uses a task-owned PostgreSQL clone bound to 127.0.0.1:15434 with max_locks_per_transaction=4096 and max_connections=20. The identical ten-table baseline was checked after a clean restore. The shared development instance on port 5433 remains unchanged. The earlier lock-memory refusal produced no accepted export; its runtime, refusal and recovery receipts are retained separately. See the dated capacity database receipt for the local image and baseline-dump digests.

Private input/output is in `storage/app/private/places-local/2026-10-01/ten-thousand-catalogue` under the original source workspace, with restrictive permissions. Raw source objects and complete exports are not committed. Dated aggregate receipts are in `2026-10-01/`.

The export is a verified local candidate catalogue, not a deployment. Do not apply it to staging or production through this rollback runner. A later release needs a current target baseline, refreshed evidence, compatible code and a separately authorized guarded promotion.
