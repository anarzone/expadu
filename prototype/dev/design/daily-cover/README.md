# Today daily-cover design

Local, interactive visual mockup approved for exploration after the user agreed to a daily cover with Composer within thumb reach. This supersedes the earlier visual proposals for review; it does not change the application.

Preview: http://127.0.0.1:8765/dev/design/daily-cover/

Raspberry #A72B58, peach #FFE2D0, butter #F7DA7E, plum #38253B and warm white #FFFCFA. Local Geist fonts; original Expadu mark. City-independent composition. The café is replaceable sample content in the featured-event position, not the product theme.

## Review

- Inspect Today on desktop and mobile, then open “The palette”.
- Type in the bottom Composer input. It opens a focused workspace.
- Submit “I want somewhere quiet”. Open details, keep the idea, refine indoors/outdoors, review and save.
- Return to Today, then open Composer again. Your request and choices remain for the current page session.
- Try company, sport, paperwork and directions to inspect different example states.

All content is illustrative. Responses are scripted, services are disconnected, and no fees, deadlines, live availability or real venue claims are supplied. The courtyard image is AI-generated supporting imagery, not a verified venue photograph or a city-specific illustration. Only session memory is used; refreshing resets the prototype.

## Verification

JavaScript syntax checked with Node. Browser inspection covered the desktop composition and a 390 × 844 phone viewport, named mobile submit control, opening Composer, quiet request, keeping a selection, detail sheet, indoor preference and empty state, returning to all options, reviewing/saving, and returning to Today with the request retained. No horizontal document overflow at the inspected phone width. Browser error log was empty during these checks. Reduced-motion rules are provided; a physical phone keyboard was not tested.

Serve the existing `prototype` folder with the repository’s local preview server. No build, package installation, backend changes or deployment is required.
