The shared language for Expadu's connected pages: one job per colour, calm surfaces, honest content and touch-first controls. Components below mirror the approved Today mock; the live mocks are embedded at the end.

Font · Geist Icons · Phosphor regular Touch targets ≥ 44px Sample data only
  1. Lead with what matters nowDeadlines, the next plan and delays come before anything else.
  2. Join things upPlans link to their journey, paperwork and the travel between them.
  3. One job per colourInk for content, orange for the main action, cyan for selection and travel.
  4. Honest by defaultUnknown stays unknown; samples and captured data are labelled.
  5. Calm, mobile-first motionShort, interruptible feedback; nothing depends on hover.

Components / Navigation

Header & navigation

Live from the Today mock

One header on every page. Five sections with fixed icon colours; the current page is marked with the cyan surface, never by changing type or spacing.

Phone
Desktop
  • Order is fixed: Today · Events · Paperwork · Travel · Services. Labels always visible.
  • Phones: a compact utility row (brand, city, Saved, account) above five equal tabs; only the tabs stay visible while scrolling. The city choice is plain text with a chevron.
  • Desktop: one 72px row; the city choice sits in an outlined pill.
  • Targets: every control is at least 44 × 44px. Composer is reached from the floating button, not from the header.

Patterns / Breakpoints

Breakpoints

Applied 7 Oct 2026

One set for every page, in CSS and in scripts that check screen width. Media queries cannot read CSS variables, so use these exact values:

Small phone≤ 359Phone360–700Tablet701–999Desktop≥ 1000
Use Query
Small phone only @media (max-width: 359px)
Phones @media (max-width: 700px)
Tablet only @media (min-width: 701px) and (max-width: 999px)
Below desktop @media (max-width: 999px)
Desktop @media (min-width: 1000px)
  • Between breakpoints, let layouts adapt by themselves: grids with a minimum column width (repeat(auto-fit, minmax(260px, 1fr))) and rows that wrap, instead of adding a new breakpoint.
  • Phone first: design at 390 × 844; check 320 for wrapping and 1024 for narrow desktops.
  • Page gutter: 16px on phones, 24px from tablet up. The only other width rule is ≥ 1500px, which caps the content width (not a layout switch).
  • Header: compact two-row header up to 700px. Today: one column up to 700px, two columns above.

Patterns / Sheets & dialogs

Sheets & dialogs

Applied to Today 7 Oct 2026

Keep the person in context. Choose the lightest surface that does the job.

  • No blurred backdrops or oversized buttons. A light scrim at most; the page stays recognisable.
  • Always closable: close button, Escape, swipe down on phones; focus returns to what opened it.
  • Motion: slide 200–280ms with the settle curve; no cross-fade that overlaps text.
  • Reference: the Event sheet, and Today's journey, plan details, forecast and Add a plan sheets. Phone sheets slide up from the bottom and close by dragging their top edge down.

Patterns / Accessibility

Accessibility

ContrastText ≥ 4.5:1 (all current pairs pass); form borders and icons that carry meaning ≥ 3:1.
Not colour aloneStatus always has words too: “Est. 10 min late”, “Not live”.
TouchTargets ≥ 44 × 44px; feedback on press, never only on hover.
FocusVisible 2px teal ring; logical order; focus returns after menus and sheets close.
NamesEvery icon button has a label (“Save Street culture night”); decorative icons are hidden.
KeyboardMenus: arrows, Home/End, Enter, Escape. Sheets trap focus until closed.
MotionRespect reduced motion: no slides or reveals, instant state changes.
Readable sizesNothing below 11px; body 15px; times use tabular figures.

Patterns / Dark mode

Dark mode

Not designed yet

The real app supports dark mode (it toggles html.dark); the mocks and this guide are light only. Because every colour is now a role token, a dark theme is one more set of values in connected/tokens.css — the components don't change.

  • To decide: a warm dark canvas that keeps the cream character, the cyan and orange at matching contrast, and how photos and posters sit on it.
  • Rule until then: new components use tokens only, so they will follow the dark set automatically.
