# Mobile menu options

Keep the menu above the content and Composer unchanged.

The owner selected option 1 and the **Travel** rename. The latest visual reference is direct-actions-v8, with the same compact labelled menu. The page content opens directly and uses dots only for secondary actions; navigation keeps familiar icons with names. The text-button direction in simplified-v6 was rejected. Earlier boards remain available for comparison.

## 1. Compact labelled navigation — recommended

- 20px outlined icons.
- 12px regular-weight labels; selected label may use medium weight.
- A 48–52px menu row and touch areas at least 44px.
- Small icon/label gap, even spacing and one soft cyan selected pill.
- Today · Events · Paperwork · Travel · Services.
- Travel replaces Departures, reflecting both route planning and stop times.

This keeps destinations understandable for newcomers while reducing the visual weight. Validate at 390px and 320px, with larger system text, before treating the dimensions as final.

## 2. Icons with only the active label

Show the name only for the selected section, with icons for the other destinations.

This reduces text further, but the inactive sections are harder to identify. It is less suitable for older or first-time users, particularly for Paperwork and Services.

## 3. Compact icon-and-label links in a scrolling row

Use inline icon/label links and allow horizontal scrolling on narrow screens.

Labels remain readable, but some destinations may be out of view. Avoid this as the default while all five primary destinations can fit in one labelled row.

Option 1 and both navigation renames are illustrated in menu-v4. Options 2 and 3 remain alternatives rather than the selected direction. No application code has changed.
