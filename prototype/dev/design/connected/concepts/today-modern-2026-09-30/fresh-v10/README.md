# Today — fresh redraw, v10

Requested 1 October 2026, using Final icon balance (v9) as the design brief.
Four new native raster sources, generated with the built-in image tool from a
blank canvas. Earlier screenshots were not supplied as edit targets. The
selected files were copied unchanged, without upscaling or post-processing.

- [Everyday](01-everyday.png)
- [Important event](02-important-event.png)
- [Route delay](03-route-delay.png)
- [Interaction storyboard](04-interactions.png)

The three desktop/mobile boards are 1536 × 1024; the storyboard is 1024 × 1536.
Open them at their original size in the comparison viewer to inspect the source.
These are static review images with sample content, not an implemented app.

The appointment anchors one agenda group, with its journey nested underneath.
Departure and arrival have a connecting directional line. In the simulated
delay state, Alternatives and its adjacent contextual Composer button use
white backgrounds and orange outlines, in a separate recovery row within that
group. City help is a plain heading; the sun remains for weather and Forecast.

Useful document, train, plus, Save and Plan identifiers remain. Saved ideas stay
separate from confirmed activities. The menu, existing Composer, review flow
and two-stage gesture removal remain the interaction references. The raster
glyphs approximate those components; their actual implementation must use the
existing vector assets and Composer component.
