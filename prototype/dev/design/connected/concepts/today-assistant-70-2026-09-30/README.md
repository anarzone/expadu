# Today — personal city assistant

Status: visual proposal for owner review, 30 September 2026.

The latest owner direction is a daily assistant with approximately 70% practical support and 30% event discovery. Orange and cyan lead the visual identity, with yellow and purple accents.

## Review boards

Each page board contains desktop and mobile views:

- [Everyday](01-everyday.png): next journey and commitment first; a central Composer workspace; direct paperwork progress and city utility; compact event discovery below.
- [Important event](02-important-event.png): a city highlight moves above useful empty-agenda and route actions. Composer, paperwork and city tools remain prominent. The featured event is not repeated below.
- [Route delay](03-route-delay.png): the journey shows scheduled and expected times, alternatives and contextual Ask. The next commitment and the practical sections remain available.
- [Interaction details](04-interactions.png): route context in Composer, exact paperwork access, separate Save/Plan outcomes, safe activity removal and empty/unavailable/stale/loading examples.

## What changed

The practical parts carry the visual personality: an illustrated journey connected to the next commitment, a main orange/cyan Composer surface, a layered document folder and yellow city utility. Event photography supports this composition.

Paperwork opens direct process rows with one chevron. Only the supplied EU Blue Card sample has a counted progress total; Address registration shows Not started.

The event-led example also demonstrates an empty agenda. It offers planning and route actions without fabricating a confirmed activity.

## Intended colour roles

- Cyan: journey orientation, editable assistant context and selected content.
- Orange: main actions and agenda emphasis. Use a sufficiently deep shade for small white text during implementation.
- Yellow: city utility and selected emphasis.
- Purple: discovery and secondary categorisation.
- Dark ink and pale canvas: readable primary content and spacing.

These are static generated design boards, not a working prototype or a measured accessibility audit. Validate responsive sizing, focus, motion and contrast during implementation. The current application and accepted prototype have not been edited by this visual exploration.

All dates, journeys, weather, progress and event examples are sample content. Event and city artwork are illustrative. No live status, actual legal advice or approved event photography is implied.
