# Today visual comparison

Two static image mockups, generated with the built-in image-generation tool on 6 September 2026. This is design exploration, not an application implementation.

- `today-refined.png`: evolution of the existing warm paper, serif and orange identity.
- `today-fresh.png`: independent rounded sans, violet and mint identity with restrained playful illustration.
- `index.html`: comparison page with individual views and actual-size inspection.

Open `index.html` directly, or serve the existing prototype directory locally:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

Preview: <http://127.0.0.1:8765/dev/design/>

The two mockups retain the same core content modules, navigation and three-column layout. Generated microcopy and detail treatment differ slightly. All displayed content is illustrative, not live weather, river, event or bureaucracy data. Category illustrations do not depict verified venue conditions or establish photo coverage. No external photo assets were used.

The fresh direction draws on the agreed qualities of content-led discovery, friendly illustration and practical city information; it does not copy a specific commercial app screen. The current Today screenshot was supplied only for the refined version. The fresh version was generated without an image reference.
